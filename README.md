# Paradise Nursery

Paradise Nursery is a React plant-shopping application where users can browse plants by category and manage a shopping cart.

## Features

- Browse air-purifying, aromatic, medicinal, insect-repellent, and low-maintenance plants.
- Add plants to the cart and see the total item quantity in the navigation bar.
- Increase or decrease quantities, remove products, and view item totals.
- Continue shopping from the cart.

## Technologies

- React
- Redux Toolkit and React Redux
- Vite

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
